# Security and Disclosure

## Public repository boundary

This repository is a public overview repository.

It intentionally does not contain:
- production source code
- runnable proof scripts
- secrets
- credentials
- deployment configuration
- enforcement internals
- sensitive runtime mechanics

## Reporting issues

If you identify a security concern in DETERMA public materials, please contact the maintainers privately.

Do not open public issues containing sensitive technical details.

## Responsible disclosure principle

Security-sensitive discussion should happen through controlled private channels.

## Product status

DETERMA is in early MVP development.

This public repository is not a production system.
