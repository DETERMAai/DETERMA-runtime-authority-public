Methodology

Ten preselected agentic repositories; 20 most recently updated PR histories with an approved review per repository; search window updated:>=2026-01-01; latest retrievable APPROVED review bound to a commit ID; compare that exact commit ID with the PR final/current head SHA.

Statistical boundary: purposive benchmark corpus, not a random population sample. Percentages describe this corpus only.
