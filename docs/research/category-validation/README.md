## Purpose

This directory defines a scientific validation track for evaluating whether **State Reconstruction Tax** and **Verified Execution State Infrastructure** represent a genuinely distinct infrastructure category for agentic AI.

The goal is not to prove the thesis by assertion. The goal is to define the thesis precisely enough that it can be tested, challenged, weakened, or rejected.

## Core Test

If DETERMA did not exist, would independent researchers still conclude that agentic AI systems need a distinct layer for verified execution-state reconstruction?

If the answer is no, the thesis is probably a product narrative rather than a category.

If the answer is yes, the thesis may justify category formation.

## Research Tracks

- prior-art analysis

### Track B — Experiments

- benchmark design
- baseline comparison
- controlled state-drift scenarios
- token / latency / tool-call measurement
- safety and correctness measurement

### Track C — Category

- naming research
- analyst-language research
- academic positioning
- industry positioning
- external adoption path
