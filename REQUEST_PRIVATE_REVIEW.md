# Request Private Review

DETERMA maintains detailed technical materials under controlled private review.

Private materials may include:
- technical architecture
- proof artifacts
- implementation direction
- MVP design
- verification approach
- current limitations
- due diligence materials

## Who private review is for

Private review is intended for:
- serious investors
- strategic advisors
- enterprise design partners
- technical diligence reviewers
- potential security or governance collaborators

## Access policy

Access is invitation-only.

Access may require:
- named individual GitHub account
- review purpose
- organization affiliation
- NDA or written confidentiality understanding
- limited review period

## Request format

Send:

```text
Name:
Organization:
Role:
GitHub username:
Reason for review:
Requested review type:
  - Investor / advisor
  - Technical due diligence
  - Design partner
  - Security review
```
